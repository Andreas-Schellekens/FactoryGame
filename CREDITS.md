# Credits

## 3D models

All 3D models in `public/assets/kenney/` are by **Kenney** ([kenney.nl](https://www.kenney.nl)),
released under [Creative Commons Zero (CC0)](https://creativecommons.org/publicdomain/zero/1.0/).
Each folder keeps the pack's original `License.txt`.

| Folder | Pack |
|---|---|
| `factory/` | [Factory Kit 3.0](https://kenney.nl/assets/factory-kit) (conveyors, machines, robot arms) |
| `city/` | [City Kit Industrial 2.0](https://kenney.nl/assets/city-kit-industrial) (buildings, chimneys, tanks) |
| `space/` | [Space Kit](https://kenney.nl/assets/space-kit) (platforms, generators, crystals, rocket parts) |
| `nature/` | [Nature Kit](https://kenney.nl/assets/nature-kit), cliffs, rocks and stones only |

Credit is not required by the license, but Kenney's work deserves it. Consider
[donating](https://kenney.nl/donate).

## Sound

All music, sound effects and ambience are synthesized at runtime with the Web
Audio API (`src/synth.js`, `src/music.js`, `src/sfx.js`, `src/ambience.js`);
there are no sample files. DELTA's voice, once recorded, is generated with
[ElevenLabs](https://elevenlabs.io) text-to-speech under the account holder's
plan terms.

## Code and art

Game code, story, procedural item meshes and the HUD's SVG art (NILE/NIHIL
marks, the Protocol: Selene mission patch, DELTA's badge) are original to this
project.
